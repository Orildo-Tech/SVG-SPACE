# Installation Guide

This guide provides detailed instructions for setting up the SVG-SPACE development environment and deploying the application.

## Prerequisites

Before installing SVG-SPACE, ensure you have the following:

- Node.js 18.0 or higher
- npm 9.0 or higher (or yarn 1.22+)
- Git 2.0 or higher
- A Supabase account (for backend services)
- A Cloudflare account (for deployment)

## Local Development Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Orildo-Tech/SVG-SPACE.git
cd SVG-SPACE
```

### 2. Install Dependencies

```bash
npm install
```

This will install all required packages including React, Vite, and other dependencies.

### 3. Environment Configuration

Create a `.env` file in the root directory:

```env
VITE_DATABASE_URL=https://your-project.supabase.co
VITE_DATABASE_KEY=your-supabase-anon-key
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-supabase-anon-key
```

Reference the `.env.example` file for the complete list of environment variables.

### 4. Start Development Server

```bash
npm run dev
```

The development server will start at `http://localhost:3000`

### 5. Build for Production

```bash
npm run build
```

This creates an optimized production build in the `dist` directory.

### 6. Preview Production Build

```bash
npm run preview
```

## Supabase Setup

### 1. Create a Supabase Project

1. Go to [supabase.com](https://supabase.com)
2. Create a new project
3. Note your project URL and anon key

### 2. Database Schema

Run the following SQL in your Supabase SQL editor to create the required tables:

```sql
-- Create icon submissions table
CREATE TABLE icon_submissions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  slug TEXT NOT NULL UNIQUE,
  title TEXT NOT NULL,
  hex TEXT,
  hexes TEXT[],
  categories TEXT[],
  license TEXT DEFAULT 'Apache-2.0',
  url TEXT,
  variants JSONB,
  status TEXT DEFAULT 'pending',
  storage_paths JSONB,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Create app config table
CREATE TABLE app_config (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Create storage bucket
INSERT INTO storage.buckets (id, name, public)
VALUES ('svg-icons', 'svg-icons', true);
```

### 3. Configure Edge Functions

Copy the Supabase edge function from `supabase/functions/submit-icon/index.ts` to your Supabase project.

## Cloudflare Workers Setup

### 1. Install Wrangler CLI

```bash
npm install -g wrangler
```

### 2. Authenticate

```bash
wrangler login
```

### 3. Configure Wrangler

Update `wrangler.toml` with your Cloudflare account details:

```toml
name = "svgspace"
compatibility_date = "2024-01-01"

[assets]
directory = "./dist"
not_found_handling = "single-page-application"
```

### 4. Deploy to Cloudflare Pages

```bash
wrangler pages deploy dist
```

## Icon Data Setup

### 1. Prepare Icon Files

Place SVG files in the `public/icons/` directory following this structure:

```
public/icons/
├── icon-slug/
│   ├── default.svg
│   ├── mono.svg
│   ├── dark.svg
│   ├── light.svg
│   └── wordmark.svg
```

### 2. Update Icon Metadata

Edit `public/icons.json` to include your icon metadata:

```json
{
  "slug": "icon-slug",
  "title": "Icon Title",
  "aliases": ["alias1", "alias2"],
  "hex": "FF5F02",
  "hexes": ["FF5F02", "FFFFFF"],
  "categories": ["Software"],
  "variants": {
    "default": "/icons/icon-slug/default.svg",
    "mono": "/icons/icon-slug/mono.svg"
  },
  "license": "Apache-2.0",
  "url": "https://example.com",
  "dateAdded": "2026-09-05",
  "collection": "community"
}
```

## Troubleshooting

### Node.js Version Issues

If you encounter version conflicts, use nvm to manage Node versions:

```bash
nvm install 18
nvm use 18
```

### Port Already in Use

If port 3000 is already in use, you can specify a different port:

```bash
npm run dev -- --port 3001
```

### Environment Variables Not Loading

Ensure your `.env` file is in the root directory and matches the format in `.env.example`.

### Build Errors

Clear the cache and reinstall dependencies:

```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```
